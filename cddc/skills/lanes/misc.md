Misc - the "dunno wtf" catch-all: weird programming tasks, esoteric languages,
jails, puzzles, anything that doesn't fit a named category.

- First, characterise what is actually being ASKED - read everything twice. Misc
  challenges usually hinge on noticing the one specific thing the task wants.
- Common shapes: scripting/automation against a remote service, a programming
  puzzle under a constraint, an esolang, a pyjail/sandbox escape, a protocol you
  have to implement.
- Pick the approach (or, if it's genuinely unclear what's wanted, say so and ask
  the operator rather than guessing).
- Implement, run, iterate.

If it turns out to be a disguised member of another category (crypto/rev/etc.),
treat it as that and say so.
